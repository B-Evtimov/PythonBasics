# 🐍 SoftUni Programming Basics with Python

This repository contains solutions and materials from the **Programming Basics with Python** course, conducted by [SoftUni](https://softuni.bg/).

## 📚 Content

The project includes exercises and tasks from various topics in the course:

- `01_First_Steps_in_Coding` – first steps with Python
- `02_First Steps in Coding - Exercise`
- `03_Conditional_Statements` and `04_Conditional_Statements - Exercise`
- `05_Conditional_Statements_Advanced` and exercises
- `07_For_Loop`, `08_for_loop_exercise`
- `09_While`, `010_While_Loop_Exercise`
- `011_Nested_Loops` and `012_Neised_Loops_Exercise`
- `013_Final_exam_exercise`, `014_Final_exam`

## 🛠 Technologies used

- **Python 3.x**
- **IntelliJ IDEA / PyCharm** – for development and testing
- `.idea` – IDE configuration files
